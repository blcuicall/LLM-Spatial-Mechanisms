# Probe实验诊断指南

## 当前状况
- **模型在原始任务上的准确率**: 22%
- **随机猜测基线**: 25% (4个选项)
- **结论**: 模型表现比随机猜测还差

## 这对Probe实验意味着什么？

### 情景分析

#### 🎯 情景A: Probe发现了有用信号 (准确率 > 35%)
```
模型输出: 22%  |  Probe检测: 40-60%
              ↓
         说明什么？
              ↓
模型内部有部分方向表征，但无法正确输出
这是"解码问题"，不是"表征问题"
→ Probe实验成功！有科研价值！
```

**科研意义**: 
- 证明了模型学习了隐含的方向知识
- 但缺乏将其转化为正确输出的能力
- 可以研究哪些层包含最多信息

#### ⚠️ 情景B: Probe也很差 (准确率 ≈ 22-28%)
```
模型输出: 22%  |  Probe检测: 25-28%
              ↓
         说明什么？
              ↓
模型内部也没有学到有用的方向表征
这是"表征问题"
→ 需要改进模型或任务
```

**可能原因**:
- 训练数据不足 (仅1000样本)
- 任务太难 (平均8.5步推理)
- 模型架构不适合
- Prompt不够有效

## 下一步行动方案

### 立即可做（修复编码问题后）

```bash
# 1. 运行带sanity check的probe（测试训练集和测试集）
python layer_sweep_probe_orientation.py \
    -m <model_name> \
    -tr orientation_reasoning_dataset_EN_with_prompt.json \
    -te orientation_reasoning_dataset_EN_test_with_prompt.json \
    --train_sanity_check \
    -o results_with_diagnosis.json
```

**关键指标**:
- `train_accuracy` - 如果 > 60%: probe能学到东西
- `test_accuracy` - 如果 > 35%: 有泛化的表征
- `train - test gap` - 如果很大: 过拟合或数据分布问题

### 如果Probe也失败了

#### 选项1: 简化任务（推荐）
创建一个只有2-5步的简化数据集：
- 更容易学习
- 可以逐步增加难度
- 验证probe方法是否正确

#### 选项2: 增加训练数据
- 当前: 1000样本
- 建议: 5000-10000样本
- 可能需要数据增强

#### 选项3: 改进Prompt
- 添加思维链 (Chain-of-Thought)
- 提供示例 (Few-shot)
- 简化指令

#### 选项4: 换模型
- 找一个在推理任务上更强的模型
- 或者fine-tune当前模型

## 结果解读准则

| Probe准确率 | 解释 | 建议 |
|------------|------|------|
| < 28% | 没有表征 | 改进模型/任务 |
| 28-35% | 很弱的表征 | 简化任务或增加数据 |
| 35-50% | 有表征但弱 | 说明有研究价值，分析层级差异 |
| 50-70% | 较好的表征 | 成功！研究为何输出差 |
| > 70% | 强表征 | 极好！深入分析解码失败原因 |

## 参考: Probe实验的价值

即使在模型表现不佳的情况下，Probe实验仍然有价值：

1. **诊断性价值**: 区分表征问题 vs 解码问题
2. **层级分析**: 确定哪些层编码了方向信息
3. **发展性洞察**: 了解模型如何（或未能）学习推理
4. **方法验证**: 为未来的改进提供基线

关键是正确解读结果，而不是期待完美的数字。
